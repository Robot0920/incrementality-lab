# Causal-inference stack, installed on demand rather than at environment build.

# resolution fails. See docs/00_decision_log.md, D9.
#
#     uv pip install --system -r requirements-causal.txt

# Versions verified against PyPI on 2026-09-24. Wheel availability drove the Python 3.12
# pin in .devcontainer/devcontainer.json:
#   dowhy     pure-Python wheel, requires >=3.9,<3.14
#   econml    wheels for cp310-cp313
#   causalml  wheels for cp311/cp312 only, requires >=3.11   <- the binding constraint
#
# confseq is deliberately absent: its newest release ships wheels only up to cp310, so on
# 3.11+ pip compiles C++ from source. The asymptotic confidence sequence is implemented in
# this repository instead, with a false-positive-rate validation harness.
